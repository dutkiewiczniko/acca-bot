Data coverage & freshness

How current is the data behind each club's stats? This measures the match sample — how many matches have detailed stats and how recent they are — not squad turnover. Measuring how much of a club's current squad is reflected in a stat would need player-level lineup data, which this dataset does not contain. Until that is gathered, treat a club with few recent matches (or none in the latest season) as having a staler statistical profile.
